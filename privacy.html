Privacy Policy

Last updated: October 15, 2026

German Publish ("the app") is a private tool used only by the owner of the YouTube channel German Steam (@german_steamtrade) to upload the owner's own videos to that channel.

Data the app accesses

  • YouTube upload access (youtube.upload) — to upload videos and set their title, description and privacy status on the owner's channel.
  • YouTube read-only access (youtube.readonly) — to read the channel name and ID to confirm that videos go to the correct channel.

How data is used and stored

  • The app runs only on the channel owner's personal computer. There is no server and no database.
  • The OAuth refresh token is stored locally on that computer and is never shared.
  • Upload results (video ID, link, time) are kept in a local log file on the same computer.
  • No data is sold, shared with third parties, or used for advertising.
  • The app does not access data of any other YouTube users.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.
